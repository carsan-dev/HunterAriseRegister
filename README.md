# Hunter Arise Register

Aplicación web interna para registrar donaciones de miembros, calcular días activos, controlar retrasos y gestionar capturas de pago.

## Tecnologías

- Python
- Streamlit
- Pandas
- Supabase Database
- Supabase Storage
- Discord API

## Funcionalidades

- Autenticación por Discord mediante código enviado por DM
- Validación de miembros por rol de Discord
- Registro de pagos/donaciones
- Cálculo automático de días cubiertos
- Panel de administración
- Historial editable de pagos
- Gestión de capturas de pago
- Métricas de días restantes y días de atraso

## Estado

Proyecto funcional desarrollado para una comunidad privada.
